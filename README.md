# 🎮 Task 1: Python Hangman Game

A simple word-guessing game built with Python. This project was created to practice programming fundamentals, logical thinking, and problem-solving.

## 📌 About the Project

Hangman is a word-guessing game in which the player tries to discover a hidden word by guessing letters. The goal is to guess the word before running out of allowed attempts.

## ✨ Features

- Interactive word-guessing gameplay
- Letter-by-letter guessing
- Win or lose messages

*Note: Keep only the features supported by your actual code.*

## 🛠️ Technologies Used

- Python

## 🚀 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

   `python hangman.py`

If your computer uses the Python launcher, you can try `py hangman.py` instead.

## 🎯 Learning Objectives

- Practice Python programming fundamentals
- Improve logical thinking and problem-solving
- Gain hands-on experience building a small project

# 📊 Task 2: Investment Portfolio Tracker

A Python program that tracks stock investments and calculates portfolio performance.

## 📌 About the Project

The Investment Portfolio Tracker helps users manage their stock investments by entering stock symbols, purchase prices, quantities, and current prices. It calculates the total investment, current market value, and profit or loss for each stock and the overall portfolio.

## ✨ Features

- Enter stock ticker symbols.
- Input purchase prices and share quantities.
- Enter current stock prices manually.
- Calculate total invested capital.
- Calculate current market value.
- Calculate profit or loss for each stock.
- Calculate overall portfolio return.
- Save portfolio details to a CSV file named `portfolio_summary.csv`.

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- CSV module
- File handling

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

   `python portfolio.py`

5. Enter the stock details when prompted.
6. Type `done` when you have finished entering your stocks.

## 🎯 Learning Objectives

- Practice Python programming fundamentals.
- Understand dictionaries and data storage.
- Perform financial calculations using Python.
- Learn file handling and CSV data storage.
- Improve problem-solving skills.

## 📝 Note

Stock prices are entered manually.The program does not currently fetch live market prices automatically.
