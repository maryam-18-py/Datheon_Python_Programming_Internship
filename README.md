# 🎮 Python Hangman Game

A simple word-guessing game built with Python. This project was created to practice programming fundamentals, logical thinking, and problem-solving.

## 📌 About the Project

Hangman is a word-guessing game in which the player tries to discover a hidden word by guessing letters. The goal is to guess the word before running out of allowed attempts.

## ✨ Features

- Interactive word-guessing gameplay
- Letter-by-letter guessing
- Win or lose messages

*Note: Keep only the features supported by your actual code.*

## 🛠️ Technologies Used

- Python

## 🚀 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

   `python hangman.py`

If your computer uses the Python launcher, you can try `py hangman.py` instead.
